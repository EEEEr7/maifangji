# 玩家试玩结论

墨水屏「夜市置业」。Node 宿主 100 局里，玩家角色是第 35–67 局（33 局 `gamer-loop`）。结论只认 PNG：`maifangji/playtest/unique/025`–`045` 是 gamer 帧，主盘对照 `016`–`024`。`vision-findings.json` 有噪声（把正常对比度标成 P0、把 SSL 失败写成缺陷），下面以截图为准。

这游戏的核很正：低买高卖、换市场烧周、房价往上爬、最后冲售楼部。一周 52 的盘面、货价乱跳、出租屋容量条，都是我想连夜刷的那套。**系统能买、能换周、能进医院/银行/售楼部。** 真正把我赶出心流的，不是数值，是底栏三行按钮叠在一起、弹层盖住现金却仍漏出底栏——买卖这种「一拍定输赢」的操作，点偏一次就是进银行、看病，或直接结束游戏。

## 手感与节奏

主盘是左市场、右出租屋，底下一整块城市按钮。开局现金 3000、健康 100、存款 0、房价 40.0 万、第 1/52 周，货仓 `0/100`（`016-pm-playing.png`）。刷过几周后能到 3/52、5/52，房价 40.8 / 41.6 万，货价跟着变，健康会掉到 99（`025-gamer-after-weeks.png`、`029-gamer-after-weeks.png`）。**换周是通的，市场是活的。**

可这盘「看价 → 下手 → 换市场过周」的节奏，被三处手感打断：

1. **货表下半截被货仓插画切开。** 新风滤芯、微商面膜、抗原试纸、阅星瞳 X4P 经常骑在冰箱/货柜线上，第四五行不像列表，像海报被撕开。低买高卖全靠扫价，扫不清就不敢下单。
2. **底栏不是一条工具带，是三层地雷。** 上：二手 / 农贸 / 批发（换周入口）；中：银行 / 医院 / 售楼部 / 中介；下：帮助 / 结束游戏 / 历程表。帮助正对着银行底下，结束游戏正对着医院底下。墨水屏手指粗、刷新慢，这布局等于把「过一周」和「退出」绑在同一块肌肉记忆上。
3. **买卖弹层出现的瞬间，现金被盖住，底栏却还露着。** 交易最需要看钱的时候看不见钱；最不该点到「结束游戏」的时候，结束游戏还在弹层下面发光。

医院、银行、售楼部都能进，但都是「打断主循环」的全屏白框，框底下的城市按钮仍清晰可见。健康的时候医院还嘲讽你去干活，病了又要 5000 块——开局只有 3000。售楼部的房源说明叠成一团，冲房这一幕本该是高潮，读起来像花屏。

一句话：数值循环想让我上瘾，控件布局在每次关键操作里劝退。

## P0

### GAMER-P0-01 底栏三行按钮重叠，点帮助会点到银行，点医院会擦到结束游戏

- **现象：** 主盘底部不是一排按钮，是三行挤在同一热区。第一行三个市场（带图标，图标压在字上）；第二行银行 / 医院 / 售楼部 / 中介；第三行帮助 / 结束游戏 / 历程表。帮助的命中盒贴在银行正下方，结束游戏贴在医院正下方，售楼部的旗标还插进结束游戏那一行。
- **证据路径：** `maifangji/playtest/unique/016-pm-playing.png`（空仓主盘，三行全露）；`maifangji/playtest/unique/028-gamer-footer.png`、`032-gamer-footer.png`、`045-gamer-footer.png`（买完货后的底栏）；`maifangji/playtest/unique/033-gamer-footer.png` 与 `037-gamer-footer.png`、`043-gamer-footer.png`（银行反白选中，正压在帮助头顶）；`maifangji/playtest/unique/035-gamer-footer.png`、`041-gamer-footer.png`（医院反白选中，正压在结束游戏头顶）。
- **误触 / 节奏影响：** 换市场=过周，是这游戏的「确认键」。帮助和银行上下粘连，想翻规则却进了存取款；医院和结束游戏上下粘连，想看病或误擦一下就可能把 52 周进度清掉。墨水屏一次误触要等整屏刷新，节奏直接断。
- **建议改法：** 底栏改成单行主操作（三个市场）+ 二级入口（银行/医院/售楼部/中介进菜单或四宫格，不要跟「结束游戏」叠层）；帮助、结束、历程表离开交易热区，放到顶栏或暂停页。命中盒之间至少留出一指宽的死区。
- **验收：** 在 480×800 真机上，连续点 20 次「帮助」，不得打开银行；连续点 20 次「医院」，不得弹出结束确认。三个市场按钮的图标不得压住汉字。

### GAMER-P0-02 弹层盖不住底栏，买卖/医院/银行过程中能点穿到城市按钮

- **现象：** 购买数量框、医院对话、银行存取款都是半高白底弹层。现金/存款被挡住，底栏三个市场和银行/医院/结束游戏仍完整露在框外。购买框下沿还叠着 5 / 2 / 1 数量快捷，位置正好落在二手 / 农贸 / 批发那一行。弹层右上角关闭是空白方框，没有「×」。
- **证据路径：** `maifangji/playtest/unique/017-pm-buy-overlay.png`（蛋白粉罐，最多买 5，框下露出 5/2/1 和三个市场）；`maifangji/playtest/unique/026-gamer-buy.png`（最多买 3，同样漏底栏）；`maifangji/playtest/unique/027-gamer-buy2.png`、`030-gamer-buy.png`、`038-gamer-buy2.png`（买新风滤芯 / 微商面膜 / 金豆金条，右上空白关闭框）；`maifangji/playtest/unique/034-gamer-hospital.png`、`040-gamer-hospital.png`（医院框压在市场按钮上沿）；`maifangji/playtest/unique/036-gamer-bank.png`、`042-gamer-bank.png`（银行三键，底栏仍在）。宿主里也有 `tap-through-overlay` 一类镜头，和这些 PNG 对得上。
- **误触 / 节奏影响：** 交易是这游戏的「按枪扳机」。弹层开着时点「确定」稍偏下，就会换市场过周，或点进结束游戏。现金被盖住，加减数量只能赌。空白关闭框不像按钮，玩家会改去点底栏找出路——于是点穿。
- **建议改法：** 弹层期间底栏命中全部吞掉（或整屏遮罩到顶）；现金/存款/容量改到弹层内常驻；关闭按钮写成「取消」或画「×」，不要空框；数量快捷放进弹层中部，不要跟市场行重叠。
- **验收：** 弹层打开时，点弹层外任何底栏坐标，状态周数、市场、是否结束游戏都必须不变。购买框内能同时看到现金和「最多可买 N」。取消有可见文字。

## P1

### GAMER-P1-01 货仓插画切开货名，扫价会扫错行

- **现象：** 市场列表下半截不是表格，是货柜/冰箱线稿直接压过文字。新风滤芯、微商面膜、抗原试纸、阅星瞳 X4P 被框线横切，价格有时落在插画格子里。中间那条「墙裂」竖缝再把价格列撕开。
- **证据路径：** `maifangji/playtest/unique/016-pm-playing.png`（新风滤芯被柜门切开，价格 1737）；`maifangji/playtest/unique/025-gamer-after-weeks.png`、`028-gamer-footer.png`、`045-gamer-footer.png`（微商面膜 + 777 骑在台面上）；`maifangji/playtest/unique/029-gamer-after-weeks.png`、`032-gamer-footer.png`、`034-gamer-hospital.png`、`038-gamer-buy2.png`、`039-gamer-footer.png`（抗原试纸 + 117 陷进冰箱）；`maifangji/playtest/unique/008-pm-help-2.png`（帮助页里阅星瞳 X4P 同样被切开，教学第一课就看不清货名）。
- **误触 / 节奏影响：** 这是倒爷游戏，货名和价格必须一眼咬死。第四五行看起来像装饰，玩家会漏点便宜货，或点到插画热区却买成另一行。帮助页示范位也不干净，新手第一印象就是「字被画吃了」。
- **建议改法：** 货表是数据层，插画只许待在表外或表底留白；至少保证每行货名、价格完整、行高足够点中。墙裂缝如果只是风格，不要穿过数字列。
- **验收：** 主盘与帮助页每一行货物的名称和价格都不被插画/裂缝切断；点该行中部，打开的就是该货物的买卖框。

### GAMER-P1-02 买卖弹层盖住现金，数量决策在盲盒里完成

- **现象：** 一点货物，白框从屏幕中部砸下来，左侧「现金 / 存款」只剩「现」「存」半边字。框上写「你最多可以购买 N 个」，N 算对了（3000/535=5，3000/824=3，3000/500=6，现金不够金豆金条时 N=0），但玩家看不见当前现金，只能信这句话。买完才在主盘看到 3000→2176（蛋白粉罐 824）或 3000→2500（微商面膜 500）。
- **证据路径：** `maifangji/playtest/unique/017-pm-buy-overlay.png`、`026-gamer-buy.png`、`027-gamer-buy2.png`、`030-gamer-buy.png`、`038-gamer-buy2.png`；买成后的主盘 `028-gamer-footer.png`（现金 2176，货仓 1/100）、`032-gamer-footer.png`（现金 2500，货仓有微商面膜）。
- **误触 / 节奏影响：** 倒爷的快感是「看还剩多少钱、能不能多囤一件」。现金被盖住，加减号就变成猜谜；N=0 时仍弹出整页框（`038-gamer-buy2.png`），还要找空白关闭框才能退，等于惩罚穷玩家。
- **建议改法：** 弹层标题区固定显示「现金 / 单价 / 可买上限」；买不起时不要进数量框，主盘 toast 一句「钱不够」；关闭用「取消」。
- **验收：** 任意购买框内能读到完整现金数字；现金少于单价时不出现数量框；确定购买后主盘现金与货仓数量立即一致（已有 3000−824=2176 这条证据，不要回退）。

### GAMER-P1-03 售楼部房源文字挤成花屏，冲房高潮读不了

- **现象：** 售楼部两张卡片。第一套没有房名，右上被黑块吃掉，只剩「售价：xx.x万」，简介「30平米的临街单间，收摊后两个人住也够用」叠成两三层；第二套「巷口老屋」名字还在，但「巷口的80平米老屋，虽旧，但进出方便」同样行叠行。可用资金 2176 / 2500 / 3000，售价 40.0–41.6 万和 120.0–124.8 万，买不起是玩法，但介绍必须能读。
- **证据路径：** `maifangji/playtest/unique/031-gamer-houses.png`（资金 2500，41.6 万档被黑块 + 叠字）；`maifangji/playtest/unique/044-gamer-houses.png`（资金 2176，同样花屏）；对照 `maifangji/playtest/unique/021-pm-houses.png`（开局 3000 / 40.0 万，同一排版病）。
- **误触 / 节奏影响：** 52 周的目标就是买房。看房这一屏如果像坏卡带，玩家会怀疑「到底买哪套、买了有什么用」，直接把长期目标扔掉，回去无脑刷货。购买键是反白的，离开在右下，误触购买（即使买不起）也会多一次弹窗往返。
- **建议改法：** 房名、售价、面积、一句简介分行，行距够墨水屏；黑块不要盖标题；买不起时购买键禁用并写清差额，避免空点。
- **验收：** 两套房的名称完整可见，简介无叠字；玩家能在 3 秒内读完面积和售价。

### GAMER-P1-04 医院「看病」被斜线划穿，健康循环不成立

- **现象：** 健康 100 时进医院，文案是「身体好好的来医院干啥，赶紧干正事儿去吧。」「看病」键上有一条斜线，像禁用又像故障；「离开」反白。过到第 5 周健康 99 再进，改口「看病需要花费5000元，你没有足够的钱看病！」看病键仍带斜线。开局现金 3000，挂号费 5000，没赚到钱就治不了。
- **证据路径：** `maifangji/playtest/unique/034-gamer-hospital.png`、`019-pm-hospital.png`（健康满，嘲讽 + 斜线）；`maifangji/playtest/unique/040-gamer-hospital.png`（健康 99、现金被挡住，5000 元门槛）；主盘健康 99 见 `025-gamer-after-weeks.png`、`041-gamer-footer.png`、`045-gamer-footer.png`。
- **误触 / 节奏影响：** 斜线让人以为按钮坏了，只会点离开。弹层同样漏底栏，看病失败后容易点穿到市场过周，健康再掉。5000 vs 开局 3000，前中期医院是死门，健康系统存在但玩不到。
- **建议改法：** 去掉看病键上的斜线；满血时直接隐藏看病，只留离开；挂号费做成「付得起的风险」（例如 200–500），或允许透支健康但明确下周惩罚。弹层同样要吞掉底栏。
- **验收：** 看病键无贯穿斜线；满血不出现可点的看病；现金 ≥ 费用时能付钱回血，主盘健康数字上升。

## P2

### GAMER-P2-01 市场图标压住按钮字，批发/农贸第一眼不像能点的周推进器

- **现象：** 二手市场、农贸市场、批发市场的线稿图标叠在汉字上，批发市场尤其糊。选中农贸时整块反黑（`029-gamer-after-weeks.png`），倒是清楚，未选中态像装饰画。
- **证据路径：** `maifangji/playtest/unique/016-pm-playing.png`、`028-gamer-footer.png`、`029-gamer-after-weeks.png`、`045-gamer-footer.png`。
- **误触 / 节奏影响：** 换市场=过周。按钮不像按钮，玩家会去点更大的银行/医院，周数推进变慢，误进子系统变多。
- **建议改法：** 图标在字上方或左侧，字单独成行；选中用框线而不是把整块涂黑到发糊。
- **验收：** 三市场名完整、不与图标相交；未玩过的人能指出「点这里过一周」。

### GAMER-P2-02 银行弹层没有金额，存款永远是 0 的旁路

- **现象：** 银行只有存钱 / 取钱 / 离开，框内不显示现金和存款。gamer 去重帧里存款始终是 0，没见到存成的反馈。弹层照样挡住「现金 / 存款」半截字，底栏仍在。
- **证据路径：** `maifangji/playtest/unique/036-gamer-bank.png`、`042-gamer-bank.png`；主盘存款 0 见 `016-pm-playing.png`、`025-gamer-after-weeks.png`、`028-gamer-footer.png`。
- **误触 / 节奏影响：** 倒爷需要把现金藏进银行防事件。现在银行像暂停菜单，点存钱不知道存多少，玩家会当它不存在，少一条策略。
- **建议改法：** 框内写清现金、存款、本次金额；给「全部存入」。
- **验收：** 存一笔后主盘存款大于 0，现金相应减少；取钱反向成立。

### GAMER-P2-03 出租屋表头「买入价数量」挤在右缘，库存数字像被切掉一半

- **现象：** 右侧表头「买入价数量」顶到屏幕右沿；库存为 1 时，最右列的「1」贴边，有的帧只剩半个笔画。货仓 1/100 的容量本身是对的。
- **证据路径：** `maifangji/playtest/unique/028-gamer-footer.png`、`032-gamer-footer.png`、`039-gamer-footer.png`、`045-gamer-footer.png`。
- **误触 / 节奏影响：** 卖出要看持仓和成本。列对不齐就会看错数量，不敢在高价周甩货。
- **建议改法：** 「买入价」「数量」分两列，数字右对齐，右边留边距。
- **验收：** 数量列完整可见，与货名、成本同行对齐。

## 买卖与换周

**买：通。** 选中货物 → 弹出数量框 → 上限按现金/单价取整（5 / 3 / 6 / 1 / 0 都对得上）→ 确定后现金减少、出租屋出现该货、容量 0/100→1/100。`016` 空仓 3000，`026` 买蛋白粉罐，`028` 现金 2176 且右侧「蛋白粉罐 824 ×1」，算术正确。`030`→`032` 买微商面膜 500，现金 2500，同样正确。

**卖：去重帧里没有独立卖出弹层。** 右侧出租屋能列出持仓（`028`、`032`、`039`、`045`），但我没看到「卖出 N 个」的确认框，也没有现金因卖出回升的前后对照。自动局的 `gamer-loop` 拍了 week1 / after-weeks / buy / buy2 / houses / hospital / bank / footer，镜头停在买入和城市入口，**不能宣称卖出已闭环。** 手工验收必须补：点右侧持仓 → 卖出 → 现金增加、容量下降。

**换周：通，而且会扣血。** `016` 为 1/52、房价 40.0 万；`029`/`032`/`034` 为 3/52、40.8 万；`025`/`028`/`045` 为 5/52、41.6 万。货池和价格都变（蛋白粉罐 535→824，金豆金条 3660→2018 等）。`025` 在还没买货时就已经 5/52、健康 99——说明只点三个市场也会过周、掉健康。这是正反馈：逛盘口要付时间。前提是 GAMER-P0-01 先拆掉，否则「过一周」和「结束游戏」分不清。

**住院：入口通，治疗不通。** 满血被嘲讽，掉 1 点血要 5000，开局付不起。看病键的斜线让人以为功能坏了。`040-gamer-hospital.png` 是「看见医院系统」不是「用医院系统」。

**看房：入口通，阅读不通，购买未在帧里成功。** `031`/`044` 能进售楼部、能看见两档价、购买/离开都在。资金 2176 vs 41.6 万，买不成是预期；但叠字 + 房名被黑块吃掉，让「看房」本身失败。

**银行：入口通，存取未在帧里成功。** 三键都在，存款一直是 0。

所以玩家循环目前是：**扫价（受插画干扰）→ 买（系统对，手感险）→ 换市场过周（系统对，误触险）→ 看房/医院/银行（能进，玩不深）→ 卖出（证据不足）。** 游戏「能玩」，但还不能「放心连打 52 周」。

## 与产品/程序员可能的分歧

1. **「墙裂和货仓线稿是风格，不是 bug。」** 玩家不同意。风格可以留在背景，不能切第四行货名。倒爷游戏的可读性就是手感。帮助页把阅星瞳 X4P 切成两半，等于教程示范「请忽略货名」。
2. **「弹层没全屏是为了让玩家还看见市场行情。」** 行情可以做成弹层内的一行摘要（货名、单价、现金）。露出底栏等于露出结束游戏。这不是信息，是误触。
3. **「空白方框就是关闭，符合极简。」** 墨水屏上空白方框=坏点。写「取消」。确定已经是黑底白字，取消用白底黑字即可。
4. **「医院 5000、满血嘲讽，是在教你别浪费行动。」** 行动浪费已经用过周扣健康表达了。挂号费高于开局现金，再叠加看病键斜线，玩家读到的不是策略，是「医院没做完」。要惩罚，先让我成功治一次。
5. **「售楼部买不起所以文字次要。」** 买不起更需要可读：面积、位置、为什么值得冲 52 周。高潮屏花掉，长期目标会塌。
6. **「自动试玩没卖出，所以卖出可能是好的。」** 可能。但 unique 里零卖出弹层，玩家侧只能打「未证实」。不要用「代码里有卖出函数」代替一帧卖出成功图。
7. **「vision JSON 已经标了 P0。」** 那份 JSON 把故事页正常「继续」键也标 P0，还有 `vision_call_failed`。优先级以这份玩家结论和 PNG 为准：先拆底栏叠点和弹层点穿，再修货名切开和售楼部叠字。

先把扳机（买卖确认）和换弹（换市场过周）从地雷阵里挪出来。数值循环已经够让人上瘾，别让控件先把人点进结束游戏。
