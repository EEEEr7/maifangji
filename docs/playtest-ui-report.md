## 1. 结论

最伤的三条（三人共识，PNG 实见）：

1. **帮助页「离开」在前 8 步等于不存在。** `draw_help` 先画主界面再 `mask_except` 把高亮以外涂黑；脚按钮不传 XIC，`draw_control` 回退成黑框黑字。未选中的「离开」落在 y=740 的黑尾巴上。第 1–8 步只能看见选中的「下一步」；第 9 步焦点换到「离开」，「下一步」同时消失。脚本能走完，是因为热区还在，人不靠对比度。
2. **主界面货名/价格被货仓插画和锯齿分界线切开。** `main_bg` 从 y=60 铺到状态栏；列表走不存在的 `goods_lm_*` / `goods_lw_*`，画出整槽描边+字，压在摊位线稿上。「阅星曈X4P」「新风滤芯」「老头乐车」在帮助第 2 步和对局主界面都被柜台切开。比价是核心循环，装饰抢了数据层。
3. **底栏三行重叠，弹层又盖不住它们。** 市场行 y=607、服务行 y=660、脚行 y=713，各高 60、间距 53，重叠 7px。「帮助」正对「银行」底下，「医院」正对「结束游戏」底下。买卖/银行/医院弹层挡住现金/存款，底栏仍画出来；overlay 期间点不着，但看起来还能点。购买框下沿的 5/2/1 快捷叠在三个市场键上。

次一级、但赢面页不能拖：售楼部选中房名黑底黑字、简介 `lineHeight=18` 叠在 24px 字上；Classic 售楼方向键只翻房源，焦点锁在「购买」。

## 2. 方法

未使用 Studio MCP、未使用浏览器 MCP。验证链路：

| 步骤 | 做法 | 产物 |
| --- | --- | --- |
| HTML 虚拟机 | `node tools/device-html/build.mjs maifangji maifangji/playtest/yehshi-device.html --model x4_pro --title 夜市置业`（wasmoon + v2 宿主单文件，480×800） | `maifangji/playtest/yehshi-device.html` |
| 100 局自动试玩 | `node maifangji/playtest/run_sessions.mjs`，`XtappLuaRuntimeV2`，按键/触摸等价真机，帧是宿主 rgba | `playtest/runs/<id>/`、`playtest/unique/`、`playtest/sessions.json` |
| 豆包视觉 | `python maifangji/playtest/vision_review.py`，账号可用视觉模型 `doubao-seed-2-1-lite-260915`（旧 `doubao-seed-1-6-*` / `doubao-1-5-vision-pro-*` 端点已关） | `playtest/vision-findings.json` |
| 三角色 | 三个子 agent 并行读 PNG + JSON + Lua，互不改生产代码 | `playtest/roles/{pm,gamer,engineer}.md` |

100 局分布（`sessions.json`，`errors=[]`，耗时 46667 ms）：

- 大厂产品经理 34 局（id 1–34，`x4_pro`）：故事 5 页、帮助 9 步、空仓、买入弹层、银行/医院/中介/售楼/历程、未开局点市场、帮助走完
- 狂热玩家 33 局（id 35–67，`x4_pro`）：换市场过周、买卖、售楼/医院/银行、底栏
- 高级程序员 33 局（id 68–90 Pro 命中/遮罩；91–100 `x4_classic` 只走方向键/OK/返回）

去重关键帧 **48** 张（目标 40–80）。X4 Pro 没有 OK 键，连点 300ms 内同坐标会被宿主判成 `double_tap`，Lua 只认 `tap`；脚本用 360ms 间隔点按，主界面未处理的 `back` 会退出到 `sys.apps`，弹层只点卡片。

视觉 JSON：48 图 / 88 条。**不能按它的 P0 排期。** 它把故事页「继续按钮可见」标成 P0，漏了帮助页黑底黑字（`007-pm-help-1.png` 零条 invisible_button），并把锯齿分界线当成裂纹。优先级以 PNG + Lua 为准。密钥不进本文件。

## 3. 按界面

### 帮助

证据：`unique/007-pm-help-1.png` … `015-pm-help-9.png`。

- 9 步文案能把规则讲完（52 周买房、低买高卖、货仓、状态栏、三市场过周、银行/医院/售楼/中介）。
- 前 8 步只见「下一步」；第 9 步只见「离开」。热区 `leave={11,740,133×60}`、`next={336,740,133×60}` 仍在。
- 根因：`mask_except`（3603）+ `draw_help` 不传 `asset_base`（3668）+ `draw_control` 无图回退黑字（3075–3082）。
- 第 2 步示范「点货物买入」，「阅星曈X4P」已被插画切断。
- 第 3 步文案「30/100 = 还剩 30」对不上 HUD「出租屋 (70/100)」（占用/容量）。
- 第 5–9 步按命中盒挖洞，医院/中介图标被切顶（XIC 画出 60px 盒）。

产品：能点完，不算「新手能看见离开」。玩家较少进帮助。程序：P0，先给脚按钮白底或 XIC。

### 主界面货列

证据：`006-pm-main-empty.png`、`016-pm-playing.png`、gamer footer 多帧、`008-pm-help-2.png`。

- `main_bg` 贴在 (0, 60)，货行 147..497 叠在摊位上。
- 列表键 `goods_lm_*` / `goods_lw_*` 包内不存在（manifest 只有弹层用的 `goods_m_*` / `goods_w_*` 100×40）。
- `draw_column_divider` 折线穿过价格列。
- 长货名没有换行/缩写。空仓健康/名声显示 0，像打残的号。

三人同意：插画可以留，但不能切第四、五行。

### 底栏

证据：`016-pm-playing.png`、`028/032/035/041/045-gamer-footer.png`、`048-engineer-classic-focus-walk.png`。

- 三行坐标与反向命中是注释里的故意设计（1105–1117）。
- 玩家把它升为 P0（误触过周 / 结束游戏）。产品标 P2（密度取舍）。程序标 P1（7px 重叠 + 图标伸出命中盒）。
- 本报告折中：**误触「结束游戏」按 P0 修热区；三行视觉密度按 P1 留缝。** 不强制改玩法入口数量。

### 弹层

证据：`017-pm-buy-overlay.png`、`026/027/030/038-gamer-buy.png`、`018` 银行、`019/034/040` 医院、`020` 中介、`024` 退出确认。

- 白框挡住现金/存款（只剩「现」「存」）。
- 底栏仍绘制；`active_actions` 只返回 overlay 键，点穿无效但看起来能点。`quit_game`/`new_game` 点框外会关层再转给主界面，和其他弹层不一致。
- 购买右上关闭是空白方框。5/2/1 快捷压在市场行。
- 医院「看病」被下层锯齿线划穿；满血嘲讽、掉 1 点血要 5000（开局现金 3000），治疗闭环未在帧里跑通。
- 买入算术是对的（3000−824=2176，3000−500=2500）。卖出弹层不在去重帧里，不能宣称卖出已闭环。

### 售楼 / 历程

证据：`021-pm-houses.png`、`031/044-gamer-houses.png`、`046-engineer-houses.png`、`047-engineer-houses-leave.png`、`022-pm-records.png`。

- 选中房名：`houses_select1` 缺失则填黑，房名仍用黑字。
- 简介 `lineHeight=18` vs 设备 24px，字叠字。
- 顶栏「返回」+ 底栏「离开」都是 `return_main`。历程表白底上「离开」可见；代码注释写明 1bpp 黑尾上会消失，才加了顶栏。
- Pro 点离开能回主界面（047）。Classic `up`/`down` 只 `move_house_selection`，焦点锁在「购买」，返回键是唯一可靠退出。

## 4. 角色分歧与共识

**共识（先做）：**

- 帮助脚按钮必须同时看得见「离开」和「下一步/完成」。
- 货名和价格不得被 `main_bg` / 分界线切开。
- 弹层打开时现金要可见，底栏不该看起来还能点。
- 售楼部房名和简介必须可读。
- 不改 8 货、均价、52 周、名声惩罚货。

**分歧：**

| 题 | 产品 | 玩家 | 程序 | 本报告 |
| --- | --- | --- | --- | --- |
| 底栏三行重叠 | P2，故意密度 | P0，地雷 | P1，7px + 图标出盒 | 热区误触当 P0，视觉咬合当 P1 |
| 弹层露出底栏 | P1，信息层级 | P0，点穿手感 | P1，绘制/命中不一致 | P0：至少吞命中 + 露出现金 |
| 锯齿分界线 | 风格线穿字，可留线 | 风格不能切价 | 限制在列空隙 | 留线，禁止穿数字 |
| 医院 5000 / 斜线 | 斜线 P1；费用属机制 | 费用劝退 + 斜线像坏键 | 斜线是下层折线穿透 | 斜线必修；5000 属机制，本阶段不改 |
| 空仓健康 0 | P2 | 未强调 | 未单列 | P2 |
| Classic 键位 | 抽测离开 | 未覆盖 | 售楼无法聚焦离开；左右无网格 | P1（售楼焦点）+ P2（主界面二维键） |
| 卖出闭环 | 未强调 | 去重帧无证据 | 代码有卖出 | 验收时补一帧，本阶段不改逻辑 |

视觉 JSON 与三人：**不采信其 P0。** 采纳它对货名切断、帮助 30/100 vs 70/100、医院斜线、售楼挤字的方向，但按 PNG 升/降优先级。

## 6. 不改的项

本阶段与下一阶段修 UI 时都不要动：

- 经营机制：52 周、三个市场过一周、银行/医院/售楼/中介职责
- 8 货及均价档（约 90 / 170 / 380 / 720 / 1500 / 3000 / 7000 / 19000）
- 货 id 3、7 卖出掉名声（微商面膜、阅星曈X4P）
- 开局现金 3000、货仓 100、房价周涨
- 医院挂号费 5000、满血嘲讽（属机制；只修按钮被斜线划穿和弹层遮挡）
- 梗货名本身（可缩写显示，不改经济 id）
- 不重生全套插画（除非为 UI-02 裁 `main_bg` 或补列表 XIC）
- 不打包提测、不手压 ZIP

卖出闭环未在 48 张去重帧里取证；修 UI 后补一帧「点右侧持仓 → 卖出 → 现金增加」，仍不改卖出公式。
